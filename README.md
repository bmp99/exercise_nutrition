# exercise_nutrition
Gym exercise app, routine tracker, and nutrition app.

# Hybrid Training & Nutrition PWA

Aplicación web progresiva (PWA) diseñada para gestionar rutinas híbridas de entrenamiento (CrossFit, Gym, Running) y estrategias nutricionales basadas en evidencia.

## Características 🚀
- **Rutinas Mecánicas & Metabólicas:** Soporte para registrar series y pesos de tren superior e inferior con referencias visuales anatómicas.
- **Temporizador de descanso integrado.**
- **Historial local:** Guardado de sesiones mediante `localStorage`.
- **Estrategia Nutricional:** Recetas estructuradas para días altos y moderados en carbohidratos.
- **Soporte Offline:** Implementación de Service Worker para uso completo sin conexión a internet.

## Despliegue en GitHub Pages 🌐
1. Sube estos archivos a tu repositorio.
2. Ve a **Settings > Pages**.
3. Selecciona la rama `main` (o `master`) y guarda.
4. Una vez publicado, abre la URL en tu dispositivo móvil y selecciona **"Añadir a la pantalla de inicio"** para instalarla como una app nativa.
